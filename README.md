# IB AFRIDI // CYBER COMMAND CENTER

A responsive, static personal portfolio for IB Afridi, designed as a premium cybersecurity command center. Built with semantic HTML, CSS, and vanilla JavaScript; the network visualization is a lightweight interactive 3D canvas rather than a large WebGL dependency.

## Run locally

Serve the repository root with any static web server. For example:

```sh
python3 -m http.server 4173 --bind 0.0.0.0
```

Then open `http://localhost:4173`.

## Notes

- The terminal is a browser-only portfolio interface and does not run operating-system commands.
- GitHub repositories are shown as a static fallback. No live API data or repository statistics are fabricated.
- Motion is reduced when `prefers-reduced-motion` is enabled.
